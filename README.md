# LinPEAS-
O **LinPEAS** (*Linux Privilege Escalation Awesome Script*) é um código aberto que identifica caminhos e vulnerabilidades para fazer escalação de privilegios

- Repositório oficial: https://github.com/peass-ng/PEASS-ng

## Instalação

Criar um diretorio no /opt para o linPEAS 
```bash
sudo mkdir -p /opt/linPEAS
cd /opt/linPEAS
```

Baixar o script oficial:
```bash
wget https://github.com/peass-ng/PEASS-ng/releases/latest/download/linpeas.sh
```

Conceder permissão de execução:
```bash
chmod +x linpeas.sh
```

## Execução

Executar o LinPEAS e salvar a saída em um arquivo de log:

```bash
./linpeas.sh | tee linlog.txt
```
